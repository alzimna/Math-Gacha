Math-Gacha

Turn your LaTeX problem set into a gacha machine. Stop grinding through contest problems in the same predictable order, let the spin decide what you solve next.

Start Practicing arrow_forward

Why use this Application?

Normally, competition problems get worked through in a fixed order, year by year, problem by problem, following whatever sequence the contest laid out. Some contests even sort by difficulty, so the ones near the end are the hardest. That's predictable, and predictable gets boring fast. Math-Gacha takes the same problem set and randomizes it. Spin, get a problem, set a timer, solve it. No fixed order, no knowing what's coming next. It's not just for solo practice, either. My friend and I used to battle over contest problems, whoever solved it first won. Math-Gacha works the same way: spin for the same problem, race the clock, see who gets there first.

How it works

  • Filter by competition, stage, or year, or leave it open and pull from the whole set.
  • Spin. Click Gacha! and watch the reel land on your next problem.
  • Not feeling it? Spin Again for a different one, no penalty for being picky.
  • Set your timer, in `mm:ss` format, and click Proceed when you're ready to start the clock.
  • Solve. Stop the timer early if you finish first, or let it run out on its own.
  • Go again. Spin Again for another problem straight away, or head back to Practice to change your filters.
