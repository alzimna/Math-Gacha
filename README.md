# Math-Gacha

# Subtitle
Suitable for person who is already bored with casual learning style and want to study with the different one. Turn your Latex file into JSON and feed it into gacha machine.

# Overview

Casually, we have our competition problems on latex file and study them by following the order of the year and what number is the problem served in that particular contests. Some contests has sorted their problems by the difficulty, the one appears in the last will be harder then the first one. This project offers something different by randoming our contest problems database.

This project consists of two phases. First we can use tex_to_csv.py for turning our Latex files into csv or JSON. Finally by using the JSON result, we can turn our problem database into spinning machine.
